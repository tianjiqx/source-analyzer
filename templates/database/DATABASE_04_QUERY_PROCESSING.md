```bash
# 查找 AST
rg "class.*AST|class.*TreeNode|struct.*Expr" --type cpp --type rust
```

### 优化器
```bash
# 查找优化器
```

### 执行器
```bash

# 查找火山模型
```

### 10.1 优化器陷阱

**陷阱1**: [陷阱名称]
- **现象**: [说明]
- **原因**: [说明]
- **正确做法**: [说明]

示例:
> **陷阱**: 统计信息过期导致优化器选择错误的执行计划
>
> **现象**: 查询突然变慢，EXPLAIN 显示使用了全表扫描而非索引
>
> **原因**: 数据分布发生变化后，统计信息未及时更新，导致代价估算错误
>
> **正确做法**: 定期自动更新统计信息，或在数据大量变化后手动触发 ANALYZE

### 10.2 执行模型陷阱

**陷阱1**: [同上格式]

示例:
> **陷阱**: 向量化执行在小数据集上反而更慢
>
> **现象**: 查询返回少量行时，向量化执行的延迟高于逐行执行
>
> **原因**: 向量化有固定开销（批次组装、SIMD 初始化），小数据集无法摊薄成本
>
> **正确做法**: 根据数据量动态选择执行模型，小数据集使用逐行执行
