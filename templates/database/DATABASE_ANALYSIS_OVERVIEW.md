# 数据库与大数据系统分析总览

> 🔥 **数据库/大数据专项分析模板** - 针对 OLTP/OLAP/HTAP/搜索引擎等系统的系统化分析方法

## 📋 概述

数据库与大数据系统是计算机科学中最复杂的软件之一，涉及存储引擎、查询优化、事务管理、分布式共识等多个核心领域。与一般应用系统不同，这类系统需要关注：

- **存储引擎**：数据物理布局、索引结构、压缩编码
- **查询处理**：SQL 解析、优化器、执行引擎
- **事务管理**：ACID 保证、并发控制、MVCC
- **分布式架构**：数据分片、复制、一致性协议
- **资源管理**：内存、CPU、IO 的精细控制

## 🔍 系统类型识别

在开始分析前，先识别系统类型，以便裁剪问题清单：

| 系统类型 | 典型代表 | 重点关注 |
|----------|----------|----------|
| **OLTP** | MySQL, PostgreSQL, OceanBase | 事务、并发、索引、连接管理 |
| **OLAP** | ClickHouse, Doris, Snowflake | 列存、向量化、MPP、聚合优化 |
| **HTAP** | TiDB, OceanBase, CockroachDB | 行列混合、资源隔离、实时分析 |
| **搜索引擎** | Elasticsearch, Meilisearch | 倒排索引、NRT、相关性打分 |
| **大数据** | Spark, Flink, Hive | 批处理、流处理、Shuffle、容错 |

## 📝 使用指南

### 快速分析（2小时）

1. 阅读项目 README 和架构文档
2. 识别系统类型（OLTP/OLAP/HTAP/搜索）
3. 梳理主干调用链（SQL → 执行 → 返回）
4. 填写 [架构概览模板](#架构概览模板)

### 深度分析（8-12小时）

1. 按 10 个维度逐一分析
2. 每个维度使用对应的问题清单
3. 根据系统类型裁剪问题（如 OLTP 重点关注事务，OLAP 重点关注向量化）
4. 记录关键发现和代码位置
5. 输出 10 个分析文档

### 综合评估（1小时）

1. 横向对比各维度设计
2. 识别设计亮点和改进点
3. 给出学习价值评分
4. 输出综合评估报告
