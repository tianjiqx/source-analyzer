```bash
find . -name "test_*.py" -o -name "*_test.py" -o -name "*.test.ts"
rg "eval|evaluate|benchmark" --type py
```

### 测试框架
```bash
rg "import pytest|def test_" --type py
rg "langchain.*eval|ragas|deepeval" --type py
```

### 测试数据
```bash
find . -name "*test*data*" -o -name "*golden*" -o -name "*benchmark*"
rg "dataset|test_cases|golden_set" --type py
```

### CI/CD
```bash
find . -name "*.yml" -path "*/.github/*"
find . -name "pytest.ini" -o -name "jest.config.*" -o -name ".coveragerc"
```

### 框架依赖
```bash
# Python
cat requirements.txt 2>/dev/null
cat pyproject.toml 2>/dev/null | grep -A200 'dependencies'

# TypeScript
cat package.json 2>/dev/null | grep -A50 '"dependencies"'

# Java
cat pom.xml 2>/dev/null | grep -A3 '<dependency'
```

### 框架 import 统计
```bash
# Python: 统计每个框架的 import 次数
grep -rh "^from \|^import " --include="*.py" . | sort | uniq -c | sort -rn | head -50

# TypeScript: 统计 import
grep -rh "^import .* from " --include="*.ts" --include="*.tsx" . | sort | uniq -c | sort -rn | head -50
```

### 框架 API 调用密度
```bash
# 找出哪些模块框架耦合最深
rg -l "from langgraph|from langchain|from crewai|from autogen|import spring_ai" --type py | while read f; do
  count=$(rg "from langgraph|from langchain|from crewai|from autogen|spring_ai" "$f" -c)
  echo "$count $f"
done | sort -rn | head -20
```

### 适配层检测
```bash
rg "class.*Adapter|class.*Facade|class.*Wrapper|class.*Provider|interface.*Provider" \
   --type py --type java --type ts --type cs -n
```

## 📊 评估标准

| 维度 | 优秀 (5分) | 良好 (4分) | 一般 (3分) | 需改进 (1-2分) |
|------|-----------|-----------|-----------|---------------|
| **评估基准** | 多维度+标准基准 | 有评估体系 | 简单评估 | 无评估 |
| **测试方法** | 单元+集成+E2E | 有测试覆盖 | 有限测试 | 无测试 |
| **质量保障** | CI/CD+回归检测 | 有 CI 集成 | 基础 CI | 无 CI |
| **框架选型** | 选型有充分论证，匹配需求 | 选型合理 | 选型可用但有更好替代 | 选型不合理 |
| **集成架构** | 有适配层，业务与框架解耦 | 有一定抽象 | 直接调用，耦合较深 | 完全绑定，难以替换 |
| **供应商锁定** | 低锁定，易于迁移 | 有一定锁定，成本可控 | 锁定较深 | 深度锁定 |
