# Agent Skill 项目分析总览

> 🧩 **Agent Skill 专项分析模板** — 针对 AI Agent Skill / 技能包项目的系统化分析方法

## 📋 概述

Agent Skill 项目是封装了可复用工作流、领域知识、工具调用规范的指令集，供 AI 编程助手（Claude Code、Cursor、Copilot、OpenClaw 等）加载执行。与传统代码库不同，Skill 项目的核心价值在于：

- **指令即代码**：Markdown / YAML 声明式描述工作流，LLM 是执行引擎
- **触发与路由**：意图识别 → Skill 匹配 → 延迟加载，发现机制是核心
- **上下文预算**：Token 限制下的指令精简与按需注入
- **平台适配**：同一 Skill 需适配多平台（Claude Code / Cursor / OpenClaw / Windsurf 等）
- **可组合性**：Skill 之间可链式调用、并行编排、层级嵌套
- **人机协作**：Skill 定义了 Agent 何时自主、何时请求人类确认

与传统代码分析的关键差异：

| 维度 | 传统代码库 | Agent Skill 项目 |
|------|-----------|-----------------|
| 执行引擎 | CPU / VM | LLM |
| 核心产物 | 可执行二进制 | 指令文档 (SKILL.md) |
| 质量指标 | 性能 / 覆盖率 | 遵循度 / 触发准确率 |
| 依赖管理 | 包管理器 | 元数据声明 |
| 测试方式 | 单元测试 | Eval / 场景回放 |
| 组合方式 | 函数调用 | 意图路由 + 会话上下文 |

                            ↓

## 📝 Skill 类型分类

### 按组织形式

| 类型 | 特征 | 示例 |
|------|------|------|
| **单体 Skill** | 单个 SKILL.md，自包含 | `mini-superpowers`, `mini-gstack` |
| **Skill 套件** | 多个 Skill 协作，共享上下文 | `superpowers` (14 skills), `agent-skills` (20+ skills) |
| **平台 Skill 生态** | Skill 发现 + 管理 + 执行平台 | `Skill_Seekers`, `OpenClaw Skills` |
| **领域 Skill 包** | 针对特定领域（PM/编码/安全） | `pm-skills`, `code-agent-skills` |

### 按目标平台

| 平台 | Skill 格式 | 特征 |
|------|-----------|------|
| **Claude Code** | `.claude/` 目录 + SKILL.md | Anthropic 官方格式，最常见 |
| **Cursor** | `.cursor/rules/` | 规则文件形式 |
| **OpenClaw** | `.openclaw/skills/` + SKILL.md | 带元数据 + 版本哈希 |
| **通用 / 多平台** | 无固定目录，SKILL.md + metadata.json | 支持多平台适配 |

## 💡 分析注意事项

1. **以 Skill 为单位**：分析的核心实体是 Skill，不是函数/类
2. **指令质量优先**：Prompt 的清晰度、约束设计、反合理化机制比代码量重要
3. **平台上下文**：理解目标平台的执行模型（如何加载、执行 Skill）
4. **可组合性关注**：Skill 不是孤岛，组合能力是核心设计决策
5. **Token 经济**：上下文预算管理是 Skill 设计的关键约束
